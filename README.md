MyJamming (Demo)

A music discovery demo app built with **React** and the **Deezer API**.  
Users can search for songs, preview results, and create demo playlists.

Features

- Real-time search using the **Deezer API**
- Clean and responsive UI
- Playlist creation (demo)
- Component-based architecture
- State management with React hooks

Tech Stack

- React 18
- JavaScript (ES6+)
- CSS
- Deezer API
- Create React App
